# Python Streamlit CRUD Operations with Azure SQL Database

This repository contains Python code for performing CRUD (Create, Read, Update, Delete) operations using Streamlit and Azure SQL Database.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

What things you need to install the software and how to install them:

- Python 3.x
- Streamlit
- pyodbc
- pandas
- A text editor (like VS Code, Sublime Text, Atom, etc.)

### Installing

A step by step series of examples that tell you how to get a development environment running:

1. Clone the repository to your local machine.
2. Install the required packages using pip:
   ```bash
   pip install -r requirements.txt
